TesseractPotato服务器群规（试行）

发布日期：2026年10月18日

为维护本群正常交流秩序，保障群成员和管理员的合法权益，现制定本群规。请所有成员入群后阅读并遵守。

一、基本原则

  1. 交流请对事不对人，尊重他人，理性表达。
  2. 可以讨论问题、提出意见、批评具体做法，但不得对他人进行人身攻击、贬损、侮辱、挑衅或阴阳怪气。
  3. 管理员同样是群成员，也应受到同等尊重；对管理方式有意见可以提出、私聊或申诉，但不得公开辱骂、贬损管理员，不得与管理员对骂。
  4. 群规自发布之日起生效。发布前的事件以提醒教育为主；但严重人身攻击、辱骂、威胁、造谣、骚扰等，管理员可先行处置。

二、禁止行为

以下行为属于违规：

  1. 人身攻击/贬损：对他人贴侮辱性、贬低性标签，或否定他人人格。
    例如：无具体事实和上下文，突然对他人说“你堕落了”“你烂了”“你不行了”“你就是个笑话”等。
    说明：“堕落”等词不是脏话，但无具体事由、直接指向个人时，属于人身贬损，可按本群规处理。
  2. 辱骂/粗口：使用脏话、侮辱性称呼攻击他人。
  3. 无事实依据的指责：没有具体事情依据，公开指责、抹黑、造谣他人。
  4. 挑衅引战：反复阴阳怪气、挑衅、激怒他人，或拉帮结派攻击他人。
  5. 骚扰：包括群内和私信中的反复@、私聊骚扰、追骂等行为。
  6. 泄露/散播他人隐私：未经本人同意，在群内公开或散播他人的真实姓名、住址、联系方式、身份证号、照片、聊天记录、账号信息等隐私内容。
    无论内容来源如何，只要未经本人同意在群内散播，均属于违规。
  7. 广告/诈骗/违法内容：发布广告、诈骗、色情、暴力、政治敏感或其他违法内容。
  8. 滥用管理权限：管理员不得无理由撤回消息、禁言、移出成员；处理应留证并说明理由。

三、对事不对人的判断标准

本群规不限于下列列举情形。判断是否属于人身攻击/贬损，重点看以下标准；符合任一标准的，均可认定为人身攻击/贬损：

  1. 是针对具体行为、具体说法，还是直接否定、贬低这个人本身；
  2. 是否有具体事实和上下文依据，还是无端贴标签；
  3. 是否使用贬损、侮辱、羞辱、嘲讽、否定人格的词语或表达；
  4. 是否公开针对个人、反复挑衅、拉帮结派攻击；
  5. 对方明确表示不适或管理员提醒后，是否仍继续。

以下仅为示例，包括但不限于：

一般不按人身攻击处理，但请语气文明：

  • 针对具体事情说：“你这件事做得不妥”“这个做法有问题”“我不认同你的观点”。
  • 朋友间明显玩笑、双方均可接受的调侃。
  • 有具体事实依据的批评和讨论。

按人身贬损处理：

  • 没有具体事由，直接对个人说“你堕落了”“你废了”等贬损标签；
  • 不讨论事情，只否定、羞辱、嘲讽对方本人；
  • 对方明确表示不适后仍继续；
  • 使用新词、谐音、隐喻、表情包、反话等方式，实际达到贬损、羞辱、否定人格效果的，同样按人身贬损处理；
  • 名为“批评”，实际不针对具体行为，只对人贴标签、否定人格的，按人身贬损处理。

四、管理秩序维护与先行处置

  1. 群成员对管理方式有意见，应就事论事提出，或私聊、申诉；不得在群内辱骂、贬损、挑衅管理员，不得与管理员对骂。
  2. 群成员对管理员进行辱骂、人身贬损、公开挑衅、造谣、骚扰，与管理员对骂，或在群内散播他人隐私的，管理员可先行禁言、移出或拉黑，并可先行撤回相关消息，无需事先与其他管理员讨论、协商或取得同意，也无需事先警告。
  3. 先行处置后，处置管理员应及时在管理员群报备，并提交事实和证据，包括：完整聊天截图、时间、上下文、是否@他人、处置理由。报备和复核均为事后程序，不影响已经作出的处置。
  4. 管理员不得以“维护管理秩序”为由，处罚正常批评、合理质疑或不同意见；只有达到辱骂、人身贬损、挑衅对骂、造谣骚扰、散播隐私等程度，才可先行处置。
  5. 其他管理员收到报备后应及时复核；如属误判或滥用权限，应纠正并在群内说明。

五、处理流程

  1. 留存证据：管理员应尽可能保存截图/聊天记录，包括时间、上下文、是否@他人。对管理员进行辱骂、贬损、挑衅，与管理员对骂，或在群内散播他人隐私等需立即制止的违规行为，管理员可先行禁言、移出或拉黑，并可先行撤回相关消息，无需事先与其他管理员讨论或取得同意，事后补交证据并报备。
  2. 先提醒后处罚：一般违规先警告并撤回不当消息；拒不改正或再次违规，升级处理。
  3. 严重违规直接处理：具体严重违规情形见第六部分，可直接禁言、移出或拉黑。
  4. 处理说明：管理员应在群内简要说明处理原因，避免无理由处罚；对辱骂、贬损、挑衅管理员或与管理员对骂的成员先行禁言、移出或拉黑后，应在管理员群报备并提交事实和证据。
  5. 申诉：被处理成员可私聊任意管理员申诉，管理员应在24小时内复核；管理员处理有误的，应及时纠正。
  6. 私信骚扰举报与证据：群成员之间发生私信骚扰、辱骂、人身贬损、造谣等行为，且属于本群规禁止行为范围的，被骚扰方可向管理员举报，管理员核实后可按本群规处置。
    举报时，举报人应提交相关聊天记录、截图或其他材料，以证明举报内容真实。无证据、证据不足或无法核实的，管理员可暂不处置，但应记录在案。
    伪造证据、诬告他人的，按本群规违规处理。管理员应保护举报人隐私，举报材料仅用于核实和处理，不随意公开。

六、严重违规情形

以下情形属于严重违规，管理员可直接禁言、移出或拉黑，无需按一般违规先提醒后处罚：

  1. 辱骂、人身贬损、公开挑衅、造谣、骚扰他人；
  2. 与管理员对骂，或辱骂、贬损、挑衅管理员；
  3. 在群内散播他人隐私；
  4. 诈骗，或发布色情、暴力、政治敏感及其他违法内容；
  5. 恶意引战、拉帮结派攻击他人；
  6. 伪造证据、诬告他人；
  7. 多次违规，经警告后仍不改正；
  8. 其他性质恶劣、严重影响群内秩序的行为。

涉及辱骂、贬损、挑衅管理员，与管理员对骂，或群内散播他人隐私的，管理员可先行处置，事后在管理员群报备并提交证据。

上述严重违规情形中，辱骂、诽谤、骚扰、散布他人隐私、诈骗、传播淫秽信息、诬告陷害等，同时受《中华人民共和国治安管理处罚法》《中华人民共和国个人信息保护法》《中华人民共和国刑法》等法律约束。群规的处理不免除、也不替代行为人依法应承担的法律责任；涉嫌违法的，管理员可保留证据并向平台或公安机关举报。

管理员可根据情节轻重调整处理级别；对管理员本人进行无具体事由的贬损，同样适用本群规。

八、管理员行为规范

  1. 管理员处理违规时应留证、说明理由、按群规执行。
  2. 管理员不得因个人情绪针对成员，不得滥用禁言、移出权限。
  3. 管理员受到无具体事由的人身贬损时，可正常按群规处理，但应避免在群内对骂。
  4. 对辱骂、贬损、挑衅管理员或与管理员对骂的成员，管理员可先行禁言、移出或拉黑，无需事先与其他管理员讨论或取得同意，事后及时在管理员群报备并提交事实和证据。
  5. 成员对管理员处理有争议的，可申诉；经复核属滥用权限的，应纠正并道歉。

九、附则

  1. 本群规自2026年10月18日起试行。
  2. 本群规所列情形为示例，不是穷尽清单。未列举但符合本群规原则和“对事不对人”判断标准的，管理员可按本群规处理。
  3. 群规未尽事宜，由管理员按“对事不对人、先提醒后处罚、处理留证”的原则处理。
  4. 对本群规有意见，可向任意管理员提出，我们会根据实际情况修订。
